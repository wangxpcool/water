# 快照页优化设计方案

## 概述

优化快照页的信息密度，采用极简列表 + 完整展开详情的模式。

## 设计目标

- 列表一眼可见关键信息（日期 + 净资产）
- 展开详情保留所有数据，但重新组织布局提升可读性
- 视觉风格统一，颜色语义化

## 布局设计

### 列表视图（折叠状态）

| 日期 | 净资产 |
|------|--------|
| 2024-03-26 | ¥128,500 |

**实现细节：**
- 一行一个快照，横向布局
- 左侧：日期（大字、加粗）
- 右侧：净资产（醒目颜色，正数绿色/负数红色）
- 点击整行展开详情
- 悬停时背景微微变灰，暗示可点击
- 无展开指示器（+/-），保持简洁

### 详情视图（展开状态）

```
┌─────────────────────────────────────────────────┐
│  2024-03-26                    [编辑] [删除]    │
│  净资产: ¥128,500                                │
├─────────────────────────────────────────────────┤
│  收入     支出     负债     盈亏     公积金 余额│
│  ¥8,000  ¥3,200  ¥5,000  +¥2,300  ¥1,500  ¥500│
├─────────────────────────────────────────────────┤
│  账户明细 (8个账户)                              │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐          │
│  │支付宝│ │微信   │ │基金   │ │信用卡│ ...      │
│  │¥5000 │ │¥3000 │ │¥50k  │ │-¥2k  │          │
│  └──────┘ └──────┘ └──────┘ └──────┘          │
└─────────────────────────────────────────────────┘
```

**实现细节：**
1. **头部**：日期 + 操作按钮（编辑/删除）+ 净资产
2. **汇总数据横排**：6列网格，标签小字，金额大字
3. **账户明细网格**：4列卡片，账户名+金额，颜色区分资产/负债
4. **配色语义化**：
   - 正数/资产：绿色 (#176a58)
   - 负数/负债/支出：红色 (#a33d31)

## 数据字段保留

展开详情保留所有现有字段：
- 收入、支出（固定支出）
- 负债总额
- 盈亏
- 公积金/公共资金
- 余额
- 账户总值
- 账户明细（所有账户的金额、类型、币种）

2. 展开详情包含所有原始数据
3. 账户明细清晰区分资产/负债
